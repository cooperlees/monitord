§report module

Serve monitord’s own health as an io.systemd.Metrics source so systemd-report (systemd ≥ 260) includes monitord in its report.

systemd-report calls io.systemd.Metrics.List / Describe on every socket in /run/systemd/report/. A source’s socket must be named as a varlink interface name, and every metric it returns must be prefixed with that name followed by a dot. Metrics without the prefix are dropped as invalid. So the socket is always REPORT_SOCKET_NAME and every family in FAMILIES starts with it.

These metrics cover monitord itself: whether its last collection run was clean, how long each collector took, and failure counters. They do not re-export the stats monitord collects, which systemd’s own report sources already publish.
