§report_collector module

Collects every io.systemd.Metrics source that systemd-report (systemd v260+) would read from /run/systemd/report/, and passes their metrics through as generic key/value stats.

Each socket in that directory is named after a varlink interface (e.g. io.systemd.Basic), and every metric it serves must be named <socket name>.<field>. Sources monitord already parses into typed stats (io.systemd.Manager, io.systemd.Network) and monitord’s own source (io.monitord) are always skipped.
